# Windows AI WPF Phi Silica example

Phi Silica is a local language model that comes pre-installed on Copilot+ PCs with Windows 11. You can use it in your Windows apps with the Windows Copilot Runtime (WCR) APIs. This little repository shows how to use Phi Silica in a .NET 9.0 WPF application.

To learn more, read the corresponding [blog post for this project on www.thomasclaudiushuber.com](https://www.thomasclaudiushuber.com/2025/05/03/use-windows-ai-in-wpf).
